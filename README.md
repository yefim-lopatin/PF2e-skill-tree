# PF2e skill tree

Копия модуля Skill Tree 2.0.3 для Foundry VTT. Автор исходного модуля — theripper93. Название изменено на PF2e skill tree; игровая логика сохранена. Отдельная адаптация под Pathfinder 2e в этой копии не выполнялась.

## Совместимость

Исходный модуль заявляет Foundry VTT 13. Работа на других версиях и внутри мира PF2e здесь не проверялась.

## Установка по ссылке

1. На стартовом экране Foundry VTT откройте «Дополнительные модули» → «Установить модуль».
2. Вставьте следующую ссылку в поле «Ссылка на манифест» (Manifest URL):

   https://github.com/yefim-lopatin/PF2e-skill-tree/releases/latest/download/module.json

3. Нажмите «Установить».
4. Откройте мир и включите **PF2e skill tree** в управлении модулями.

Обновления доступны через обычную проверку обновлений Foundry VTT.

Для ручной установки скачайте `PF2e-skill-tree.zip` из [последнего выпуска](https://github.com/yefim-lopatin/PF2e-skill-tree/releases/latest) и распакуйте в `Data/modules`. Должен получиться путь `Data/modules/skill-tree/module.json`.

Если Skill Tree уже установлен, сначала сохраните резервную копию его папки. У этой копии сохранён идентификатор `skill-tree`: она заменяет исходный модуль, а не устанавливается рядом с ним.
