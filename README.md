# PF2e skill tree

Личная копия модуля Skill Tree 2.0.3 для Foundry VTT. Автор исходного модуля — theripper93. Название изменено на PF2e skill tree; игровая логика сохранена. Отдельная адаптация под Pathfinder 2e в этой копии не выполнялась.

## Совместимость

Исходный модуль заявляет Foundry VTT 13. Работа на других версиях и внутри мира PF2e здесь не проверялась.

## Установка

1. Войдите в GitHub под своей учётной записью и откройте [последний выпуск](https://github.com/yefim-lopatin/PF2e-skill-tree/releases/latest).
2. Скачайте архив `PF2e-skill-tree.zip` из файлов выпуска.
3. Остановите Foundry VTT и распакуйте архив в каталог пользовательских данных `Data/modules`. Должен получиться путь `Data/modules/skill-tree/module.json`.
4. Запустите Foundry VTT, откройте мир и включите **PF2e skill tree** в управлении модулями.

Если Skill Tree уже установлен, сначала сохраните резервную копию его папки. У этой копии сохранён идентификатор `skill-tree`: она заменяет исходный модуль, а не устанавливается рядом с ним.

Репозиторий закрытый, поэтому установка по обычной ссылке в Foundry не настроена. Обновления устанавливаются вручную из выпусков. Ссылка автоматического обновления исходного автора удалена, чтобы обновление не заменяло личную копию.

Авторство исходного модуля сохранено в `module.json`. Этот репозиторий не предоставляет новую лицензию на исходный код.
